# PageTurner 双形态人工回归清单

> v1.0.78 建立。用途：每次发版（或动引擎核心 / 设置页 / 构建脚本）前，按本单过一遍。
> **dylib 优先**：deb 形态需要 macOS + Theos 工具链才能构建，而 dylib 可本地一键
> （`scripts/build_dylib.sh`）且覆盖用户日常使用场景（巨魔注入）；deb 只补差异项（见 D 节）。

> v1.0.78 起为六件套）与同一份共享设置页（`common/PTUI*`），**行为应完全一致**；
> 差异仅在「配置路径 / 总开关门控 / hook 安装方式 / 菜单形态」。

## A. 构建

| # | 步骤 | 预期 |
| --- | --- | --- |
| A1 | `bash scripts/build_dylib.sh` | 前置检查通过 → arm64 + arm64e 双架构 → strip → lsid 签名 → 符号审计全过；产物在 `out/`（或脚本所示路径） |
| A2 | `bash scripts/check_syntax.sh && bash scripts/check_imports.sh` | 两个脚本 OK（60 个文件） |
